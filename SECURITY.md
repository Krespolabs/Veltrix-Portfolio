# Security Policy

## Supported scope
This repository contains the Veltrix public portfolio and its documentation. Report vulnerabilities affecting this repository, its future website, or its publication pipeline.

## Reporting a vulnerability
Please do not publish exploitable details in a public issue. Contact the repository owner privately through GitHub's private vulnerability reporting feature if enabled, or use a verified contact channel listed on the official Veltrix website once available.

Include:
- A clear description and affected component
- Steps to reproduce
- Potential impact
- Suggested mitigation, if known

## Security expectations
- Never commit credentials, tokens, private keys, or production secrets.
- Use least-privilege access for integrations.
- Keep dependencies updated and review security alerts.
- Treat external data as untrusted.
- Do not expose private repository information or personal data.
- Rotate any credential that may have been exposed; removing it from the latest commit is not sufficient.

We will acknowledge and assess reports as promptly as practical. Please allow reasonable time for investigation and remediation before public disclosure.
