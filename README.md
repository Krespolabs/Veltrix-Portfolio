# Veltrix Portfolio

The official portfolio and engineering hub of **Veltrix**, presenting verified work across software products, artificial intelligence, automation, cybersecurity, creative technology, and digital ventures.

The portfolio is designed to show not only what is being built, but also how it is engineered. Project status, technical documentation, and public evidence are treated as first-class content.

## Principles
- Evidence over claims.
- Clear distinction between ideas, prototypes, beta products, and live products.
- Documentation-first engineering.
- Privacy and security by default.
- Accessible, responsive, performant experiences.
- GitHub as the source of truth.

## Technology direction
The planned website stack is Next.js App Router, TypeScript, and Tailwind CSS. The application has not yet been scaffolded; see [the blueprint](docs/BLUEPRINT.md).

**Current phase:** Phase 0 — Foundation and governance.
